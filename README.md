# Jajiga Tracker 🏡

ردیابی قیمت کلبه‌های چوبی و سوئیسی در منطقه بابلکنار (سیدکلا، قرآن تالار، گونه کلا، شیردارکلا) از سایت جاجیگا.

## هدف
جمع‌آوری و پایش قیمت‌های رقبا برای قیمت‌گذاری بهتر کلبه Swiss Chalet در سیدکلا.

## فاز فعلی (۱)
جمع‌آوری دستی اطلاعات از سایت jajiga.com و ذخیره در فایل JSON.

## فاز بعدی (۲)
اتوماتیک‌سازی جمع‌آوری با اسکریپت و برنامه‌ریزی هفتگی.

## فاز بعدی (۳)
داشبورد تحلیلی + آلerts تلگرامی برای تغییر قیمت‌ها.
