# Jajiga Tracker 🏡

ردیابی قیمت کلبه‌های چوبی و سوئیسی در منطقه بابلکنار (سیدکلا، قرآن تالار، گونه کلا، شیردارکلا) از سایت جاجیگا.

## هدف
جمع‌آوری و پایش قیمت‌های رقبا برای قیمت‌گذاری بهتر کلبه Swiss Chalet در سیدکلا (جاجیگا ۳۲۹۷۵۸۵).

## وضعیت فعلی (مرداد ۱۴۰۵)
- **۵۲ کلبه** در ۴ روستا، با مشخصات کامل (قیمت، خواب، متراژ، ظرفیت، امتیاز، نظرات، میزبان)
- داشبورد HTML تعاملی با: نمودار قیمت، فیلتر، مرتب‌سازی، صفحه‌بندی، ویرایش
- نام میزبان‌ها از API جاجیگا (`api.jajiga.com/api/room/{id}` → `host.name`) استخراج شده

## ساختار پروژه
```
jajiga-tracker/
├── dashboard.html          # داشبورد اصلی (تک‌فایل، بدون وابستگی)
├── server.py               # سرور محلی پورت ۸۰۸۰
├── data/
│   └── all-cabins.json     # دیتابیس اصلی (۵۲ کلبه)
├── scripts/
│   ├── collector.py        # اسکریپت جمع‌آوری (فاز بعدی)
│   └── rebuild_dashboard_data.py  # بازسازی دیتای embedded در dashboard.html
├── requirements.txt
└── README.md
```

## استفاده
1. **روش ساده:** `dashboard.html` رو مستقیم توی مرورگر باز کن (دابل‌کلیک)
2. **روش سرور:** `python server.py` → `http://localhost:8080/dashboard.html`
3. برای دیدن نمودارها اینترنت لازمه (Chart.js از CDN)؛ بقیه آفلاین کار می‌کنه

## ویرایش و ذخیره‌سازی
- دکمه ✏️ در هر ردیف → ویرایش مشخصات کلبه
- ذخیره در `localStorage` مرورگر → بعد از رفرش باقی می‌مونه
- دکمه **⬇ خروجی** → دانلود JSON پشتیبان (شامل ویرایش‌های دستی) — هفتگی بگیر و توی پوشه نگه دار
- دکمه **⬆ ورودی** → بازگردانی از فایل پشتیبان
- دکمه **↺ بازنشانی** → برگشت به دیتای اصلی

## نکات فنی جاجیگا
- API: `https://api.jajiga.com/api/room/{id}` — قیمت در `min_price`، میزبان در `host.name`
- جستجوی دسته‌بندی: `/s/babolkenar/cottage` (pagination سایت شکسته — باید مرورگر/API مستقیم)
- قیمت پایه از باکس «نرخ هر شب از» — نه قیمت تخفیفخورده (لحظه آخری)
