# پلن ارتقای ظاهری — داشبورد تحلیل سیدکلا

**تاریخ:** 2026-08-01
**وضعیت:** پیشنهاد — منتظر تأیید

---

## ۱. ارزیابی وضعیت فعلی

داشبورد فعلی (`seydkola-analysis-dashboard.html`) عملکردی و کامل است، اما از نظر ظاهری:

- **طرح کلی (Layout):** کارت‌های شیشه‌ای (glassmorphism) تیره + نمودار — شبیه قالب عمومی داشبوردها
- **نوع (Typography):** Vazirmatn برای همه‌چیز — بدون شخصیت
- **رنگ:** آبی-سبز گرادیان تکراری — بدون داستان
- **هیچ امضای بصری (signature)** ندارد — فقط یک داشبورد تحلیلی دیگر

## ۲. موضوع و مخاطب

- **موضوع:** کلبه‌های چوبی و سوئیسی در جنگل‌های بابلکنار (مازندران)
- **مخاطب:** صاحب یک کلبه (شما) که می‌خواهد بازار رقبا را بفهمد — تحلیلگر-مالک
- **کار صفحه:** فهمیدن «چه چیزی قیمت و اشغال را بالا می‌برد» در یک نگاه

## ۳. کانسپت طراحی: «جنگل در شب»

داشبورد تحلیلی است، نه فروشگاه. پس به‌جای تصاویر جنگل، **حس جنگل شبانه** را با پالت رنگی و بافت منتقل می‌کنیم:

### پالت رنگی (۴-۶ رنگ)
```
--bg:      #0B1020   (شب عمیق جنگل — آبی‌تیره‌تر از فعلی)
--card:    #111A2E   (کارت‌ها — آبی‌شب)
--accent:  #E8B44F   (چراغ کلبه/آتش — زرد کهربایی، عنصر گرم در دل شب)
--leaf:    #4CAF7D   (سبز برگ — داده‌های مثبت)
--pine:    #2E7D5B   (سبز کاج — خطوط و مرزها)
--mist:    #8FA3BF   (مه صبحگاهی — متن کم‌رنگ)
```

**چرا؟** به‌جای آبی-سبز تکراری، یک **زرد کهربایی گرم** (چراغ کلبه در شب) به‌عنوان رنگ اصلی استفاده می‌شود — این انتخاب از دنیای موضوع (کلبه‌های جنگلی) می‌آید، نه از قالب‌های آماده.

### تایپوگرافی
```
--font-display: 'Vazirmatn' 800 — برای تیترها و اعداد بزرگ (همان فارسی قوی)
--font-body:    'Vazirmatn' 400-500 — برای متن
--font-data:    'IBM Plex Mono' — برای اعداد/مقادیر (شخصیت داده‌ای)
```
- اعداد با فونت **IBM Plex Mono** (فونت داده/تکنیکی) — این تفاوت ظریفی ایجاد می‌کند که اعداد «داده» هستند، نه متن
- Vazirmatn با وزن‌های مختلف برای سلسله‌مراتب

### Layout — «کارت‌های کاغذی شب»
- به‌جای glassmorphism، **کارت‌های تخت با لبه‌های تیزتر** (border-radius کوچک‌تر: 8px) + خط‌های ظریف
- **نوار کناری راست** برای ناوبری بین بخش‌ها (Sticky) — با شماره‌بخش که واقعاً ترتیب است
- **بخش‌های جدا از هم با خطوط ظریف** به‌جای سایه‌های سنگین

### امضای بصری (Signature) — «داده‌ها به‌عنوان جنگل»
- **نمودار پراکندگی قیمت-متراژ** با نقاطی که شبیه **درخت‌های جنگل از بالا** هستند (اندازه/رنگ نقاط نشان‌دهنده ویژگی‌ها)
- **نوار پیشرفت‌های خطی** به‌جای میله‌ای برای مقایسه امکانات
- **هایلایت لوکیشن شما** با یک **نقطه طلایی درخشان** (چراغ کلبه شما در جنگل) — با انیمیشن نبض ملایم

### انیمیشن (محدود و معنادار)
- **لود تدریجی بخش‌ها** با fade-in (یک بار هنگام باز شدن)
- **نبض ملایم** روی نقطه لوکیشن شما
- hover روی ردیف‌های جدول (هایلایت)
- احترام به `prefers-reduced-motion`

## ۴. تغییرات مشخص

| بخش | فعلی | جدید |
|------|-------|------|
| پالت | آبی-سبز تیره | شب جنگل + کهربایی + سبز برگ |
| کارت‌ها | glassmorphism (blur) | تخت، لبه‌های ظریف، خطوط جداکننده |
| تیتر | گرادیان آبی-سبز | کهربایی گرم + زیرخط ظریف |
| اعداد | Vazirmatn | IBM Plex Mono |
| ناوبری | بدون | استیکی سمت راست با بخش‌ها |
| ماتریس همبستگی | جدول ساده | سلول‌های رنگی با hover و tooltip |
| لوکیشن شما | ردیف طلایی | نقطه درخشان با نبض + کارت ویژه |
| نمودارها | استاتیک | hover + tooltip + رنگ‌های معنادار |
| فوتر | ساده | با اعتبار داده (منبع، تاریخ، تعداد) |
| موبایل | واکنش‌گرا | + منوی همبرگری |

## ۵. ریسک‌ها و ملاحظات

- **تضاد رنگ:** کهربایی روی آبی‌تیره باید کنتراست کافی داشته باشد (تست WCAG)
- **فونت IBM Plex Mono:** از Google Fonts — نیاز به اینترنت (مثل Chart.js فعلی)
- **خوانایی:** متن مه‌رنگ (`mist`) فقط برای موارد کم‌اهمیت
- **عملکرد:** بدون افزایش حجم محسوس (همه‌چیز همان CSS + فونت جدید)
