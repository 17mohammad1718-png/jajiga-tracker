## 2. تجزیه و تحلیل تکنولوژیهای کلیدی (برای ما)

### 2.1 changedetection.io (⭐32K) — ⭐ نزدیکترین به ما
**مشکل حلشده:** نظارت بر تغییرات وبسایت + هشدار.

**ویژگیهای قابل اقتباس:**
1. **تشخیص تغییر قیمت** — دقیقاً همان «هشدار قیمت» که میخواستیم؛ این پروژه در خط اول README خود میگوید: «ایدهآل برای نظارت بر تغییرات قیمت»
2. **اعلانهای متنوع:** Discord, Email, Slack, **Telegram**, Webhook
3. **تشخیص هوشمند با AI** — «فقط وقتی قیمت زیر X شد خبر بده» — با LLM
4. **تاریخچه diff** — مقایسه word/line/character از تغییرات

**چه چیزی از آن برای ما:**
- ایده «قوانین هشدار هوشمند» — به جای اینکه هر تغییر قیمت خبر بدهیم، فقط تغییرات مهم (مثلاً کاهش ۱۰٪) را خبر بدهیم
- ایده «خلاصه تغییر» — به جای diff خام، یک جمله بدهیم: «قیمت از ۳.۵M به ۳.۲M کاهش یافت»

### 2.2 Scrapling (⭐71K) — آینده اسکرپینگ
**مشکل حلشده:** اسکرپینگ تطبیقپذیر با تغییرات سایت + دور زدن ضدبات.

**ویژگیهای قابل اقتباس:**
1. **`adaptive=True`** — وقتی ساختار سایت عوض میشود، خودش عناصر را پیدا میکند. **این دقیقاً ریسک ماست** (تغییر DOM جاجیگا)
2. **StealthyFetcher** — دور زدن Cloudflare/Turnstile بدون کد اضافه
3. **Spiders** — خزش همزمان با pause/resume و پروکسی

**چه چیزی از آن برای ما:**
- اگر جاجیگا روزی محدودیت بگذارد، میتوانیم از `StealthyFetcher` استفاده کنیم
- ایده «تطبیقپذیری»: کد ما باید طوری نوشته شود که تغییرات کلاسها/ساختار را تشخیص دهد و خودش را اصلاح کند

### 2.3 Crawlee-Python (⭐9.3K) — ربات حرفهای
**مشکل حلشده:** رباتهای پایدار با مدیریت درخواست و خطا.

**ویژگیهای قابل اقتباس:**
1. **مدیریت خودکار Rate Limit** — بین درخواستها صبر میکند
2. **retry با backoff** — وقتی خطا داد دوباره تلاش میکند
3. **مدیریت پروکسی**

**چه چیزی از آن برای ما:**
- به جای `urllib` ساده، از این برای اسکرپینگ ۳۶۹ کلبه استفاده کنیم
- مدیریت خطا بهتر = داده تمیزتر

### 2.4 Prophet (⭐20K) — پیشبینی قیمت
**مشکل حلشده:** پیشبینی سری زمانی با فصلبندی (تعطیلات، فصلها).

**ویژگیهای قابل اقتباس:**
1. **پشتیبانی از تعطیلات ایرانی** — `custom_seasonality` برای تعطیلات نوروز/تابستان
2. **پیشبینی روند قیمت** — با داده ۳۰ روزه
3. **تشخیص ناهنجاری** — وقتی قیمت غیرعادی است

**چه چیزی از آن برای ما:**
- پیشبینی: «قیمت کلبهها در شهریور X خواهد بود»
- تشخیص ناهنجاری: «قیمت این کلبه نسبت به بقیه غیرعادی است»

### 2.5 n8n (⭐198K) — اتوماسیون بدون کد
**مشکل حلشده:** اتصال ابزارها بدون نوشتن کد.

**ویژگیهای قابل اقتباس:**
1. **۴۰۰+ اتصال آماده** — Telegram, Excel, Google Sheets, Slack
2. **گردش کار بصری** — بدون کد
3. **self-hosted** — روی سیستم خودمان

**چه چیزی از آن برای ما:**
- برای کاربری که نمیخواهد کد بزند: یک گردشکار n8n که هر روز قیمتها را بگیرد و به تلگرام بفرستد
- اتصال به Google Sheets برای ذخیره تاریخچه

### 2.6 Huginn (⭐49K) — عاملهای مستقل
**مشکل حلشده:** ساخت عاملهای نظارت که بهجای ما عمل میکنند.

**ویژگیهای قابل اقتباس:**
1. **عاملهای مستقل** — هر عامل یک کار: «قیمت را چک کن»، «تغییر را خبر بده»
2. **زنجیره عاملها** — یک عامل خروجی دیگری را مصرف میکند
3. **اعلان در ۱۰۰+ سرویس**

**چه چیزی از آن برای ما:**
- همان معماری: یک عامل «اسکرپر»، یک عامل «تحلیلگر»، یک عامل «اعلاندهنده» — جدا از هم، قابل تعویض

### 3.1 از changedetection.io — «قوانین هشدار هوشمند»

```python
# به جای: هر تغییری خبر بده
# این کار را بکن: فقط وقتی مهم است خبر بده
def should_alert(old_price, new_price, rule):
    if rule == 'drop_10pct':
        return new_price < old_price * 0.9
    if rule == 'under_2M':
        return new_price < 2_000_000
    return False  # همهچیز دیگر را نادیده بگیر
```

```python
# به جای hardcode کردن selector:

SELECTORS = {
    'price': ['[class*="price"]', '[data-test="price"]', '.nightly-rate'],
}
def find_price(doc):
    for sel in SELECTORS['price']:
        el = doc.css_first(sel)
        if el:
            return parse_price(el.text)
```

### 3.3 از Crawlee — «اسکرپر مقاوم»
```python
import time, random
def fetch_with_retry(url, max_retries=3):
    for attempt in range(max_retries):
        try:
            resp = requests.get(url, headers=HEADERS, timeout=30)
            if resp.status_code == 200:
                return resp.json()
        except Exception:
            pass
        time.sleep(2 ** attempt + random.random() * 2)  # backoff تصادفی
    return None
```
