## 1. خلاصه اجرایی (TL;DR)

پروژه جاجیگا الان یک **دیتاست ۵۲ کلبه در ۴ روستا + داشبورد** است. این تحقیق نشان داد:

1. **۵ فیلد جدید کشف شد** که در دیتاست ما نیست ولی روی کارتهای زنده سایت موجود است (رزرو موفق، ممتاز، رزرو فوری، تخفیف مدت، تعداد عکس).
2. **همبستگی قیمت و امتیاز ~۰-** است → بازار بابلکنار **ناهماهنگ** است؛ فرصت قیمتگذاری هوشمند.
3. **جایگاه کلبه خود کاربر (۲.۷۵M با امتیاز ۵.۰):** گرانترین نیست ولی ۱۲ رقیب ارزانتر دارد — مزیت رقابتی: امتیاز کامل ۵.۰ + ۱۰۰ متر.
4. **۳ ایده با اولویت بالا** پیشنهاد شد (هشدار قیمت، ردیاب قیمت روزانه، نقشه تعاملی).

### 3.4 همبستگی قیمت ↔ امتیاز

```
همبستگی = -0.048  →  تقریباً صفر
```

> 🔍 **معنی:** در بابلکنار **قیمت گران ≠ کیفیت بهتر**. این یعنی بازار از نظر قیمتگذاری بهینه نیست — کاربرانی که بیشتر میپردازند لزوماً کیفیت بهتری نمیگیرند. **برای کاربر به این معنی است:** اگر امتیاز و تجهیزات خوبی دارد، میتواند بدون نگرانی از دست دادن مشتری، قیمت را افزایش دهد.

## 4. دادههای کشفشده روی کارتهای زنده (NEW!)

هنگام بررسی زنده سایت، **۵ فیلد جدید** روی کارتهای جاجیگا پیدا شد که در دیتاست ما نیست:

| فیلد | نمونه واقعی | کاربرد |
|---|---|---|
| **رزرو موفق** (X+ رزرو) | ۶۰۰+، ۱۰۰+، ۵۰+ | محبوبیت = تقاضای واقعی |
| **ممتاز** (نشان طلایی) | ✅ | اعتبار + جایگاه ویژه در فیلترها |
| **رزرو فوری** | ✅ | پذیرش خودکار = تبدیل بیشتر |
| **تخفیف مدت** (۱۰٪ از ۳ شب) | ۱۰٪ از ۳/۵/۶/۱۰ شب | استراتژی افزایش مدت اقامت |
| **تعداد عکس** | ۱۵، ۲۰، ۲۳ | کیفیت لیستینگ |

**نمونه دادههای واقعی (کارت اول):**
```json
{
  "id": 3157431,
  "title": "کلبه چوبی جنگلی در بابلکنار - نزدیک مرزیکلا",
  "bookings": "600+",
  "excell": true,        // ممتاز
  "instant": true,       // رزرو فوری
  "price": 1200000,
  "rating": 4.7, "reviews": 279,
  "discount": null
}
```

> 💡 **چرا مهم است:** «رزرو موفق» تنها شاخص تقاضای واقعی بازار است — قیمت و امتیاز به تنهایی نمیگویند چه کسی مشتری بیشتری دارد. با این داده میتوان فهمید آیا کلبه گران با ۶۰۰ رزرو موفق، بازار بهتری از کلبه ارزان با ۲۰ رزرو دارد.

| **۲.۷۵M** | **۵.۰ (۴)** | **← کلبه کاربر** |

### تحلیل SWOT

**قوتها:** امتیاز کامل ۵.۰ • زیربنای ۱۰۰ متر (بزرگترین در رنج قیمتش) • جایگاه وسط بازار
**ضعفها:** فقط ۴ نظر (اعتماد پایین) • قیمت از میانگین روستا بالاتر
**فرصتها:** فعالسازی «ممتاز» و «رزرو فوری» • تخفیف مدت ۱۰٪ از ۳ شب • جمعآوری نظر بیشتر (پاسخ به نظرات)
**تهدیدها:** ۳ رقیب با امتیاز ۴.۸–۴.۹ و قیمت ۱.۹–۲.۷M • رقبای ۱۷۴+ نظر (اعتماد بالا)

### پیشنهاد قیمتگذاری
- **کوتاهمدت:** قیمت ۲.۷۵M را نگه دار (منطقه ۲–۳M پرتقاضاترین است)
- **میانمدت:** بعد از ۱۰+ نظر، تست افزایش به ۳M (فاصله ۳–۴M خلوت است → تمایز)
- **هرگز زیر ۲.۵M نرو** — رقبا در ۱.۹–۲.۵M با نظرات زیاد، شکست میخورند

## 6. ایدههای جدید (Roadmap)

### اولویت ۱ — زودبازده (این هفته)

1. **🚨 هشدار قیمت (Price Alert)**
   - اسکن روزانه با cron؛ اگر قیمت یک کلبه رقیب تغییر کرد → اعلان
   - پیادهسازی: `python scripts/price_watch.py` + cron روزانه
   - خروجی: فایل `data/price_history.json` + اعلان در داشبورد

2. **📈 ردیاب قیمت روزانه (Price History)**
   - تاریخچه قیمت هر کلبه را ذخیره کن (اولین نسخه: روزانه)
   - بعد از ۲ هفته: نمودار روند قیمت در داشبورد
   - پیادهسازی: افزودن `price_history: [{"date": "...", "price": N}]` به هر کلبه

3. **🗺️ نقشه تعاملی**
   - دیتاست فعلی URL دارد؛ موقعیت جغرافیایی (lat/lng) از صفحه هر کلبه استخراج میشود
   - نقشه Leaflet با مارکرهای رنگی بر اساس قیمت (جاجیگا خودش این کار را میکند — ولی ما میتوانیم برای روستاهای خودمان انجام دهیم)
   - پیادهسازی: `dashboard.html` + Leaflet CDN

### اولویت ۲ — میانمدت (۲–۴ هفته)

4. **📊 فیلدهای جدید در داشبورد** (کشفشده در این تحقیق)
   - افزودن ستونهای: رزرو موفق، ممتاز، رزرو فوری، تخفیف مدت
   - استخراج: بازدید صفحه `/s/babolkenar/cottage` با مرورگر (یکبار) + API
   - مزیت: فهمیدن اینکه کدام رقیب واقعاً مشتری دارد

5. **🔔 اعلان تلگرام**
   - ارسال گزارش هفتگی قیمت به تلگرام (پترن قبلی در skill وجود دارد)
   - شامل: تغییرات قیمت، کلبههای جدید، کلبههای حذفشده

6. **🏆 تحلیل محبوبیت**
   - ترکیب «رزرو موفق» + امتیاز + قیمت → اسکور محبوبیت
   - «برترینهای بابلکنار» بهصورت خودکار

### اولویت ۳ — بلندمدت (۱–۲ ماه)

7. **🤖 تشخیص کلبههای جدید**
   - اسکن هفتگی کل لیستینگها → شناسایی کلبههای جدید
   - اعلان: «۳ کلبه جدید در بابلکنار اضافه شد»

8. **📉 پیشبینی قیمت**
   - بعد از ۳۰ روز داده تاریخی: پیشبینی روند قیمت (فصلی، تعطیلات)
   - مدل: میانگین متحرک ساده + تحلیل فصلی

9. **📋 خروجی اکسل/CSV**
   - دکمه خروجی CSV برای تحلیل خارجی (Excel)
