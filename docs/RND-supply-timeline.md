# RND — Supply Timeline Dashboard (نقشه عرضه بابلکنار)

> Created: 2026-08-01 · Project: jajiga-tracker

## Goal

داشبوردی که روند اضافه‌شدن میزبان‌ها و اقامتگاه‌های جدید در بابلکنار را نشان می‌دهد —
شاخص «میزان عرضه» (supply) منطقه، با تایم‌لاین ماه‌به‌ماه.

## Why this works (data sources)

جاجیگا تاریخ ساخت اقامتگاه را مستقیم نمی‌دهد. سه سیگنال موجود:

| سیگنال | منبع | دقت |
|---|---|---|
| `member_since` میزبان | `data/hosts-babolkenar.json` (قبلاً جمع‌آوری شده) | **دقیق** — تاریخ عضویت |
| `pictures[].created_at` (اولین عکس) | `GET /api/room/{id}` | تخمینی — عکس‌ها هنگام ثبت آپلود می‌شوند |
| اولین نظر (`/reviews` آخرین صفحه) | `GET /api/room/{id}/reviews` | تخمینی — فقط وقتی عکسی نباشد |
| اسنپ‌شات روزانه | `scripts/supply_snapshot.py` | **دقیق** — از 2026-08-01 به بعد |

قانون حد پایین: اقامتگاه نمی‌تواند قبل از عضویت میزبان ساخته شده باشد →
`est_date = min(photo, review)` و اگر از `host_created_at` کوچک‌تر بود → clamp.

## Architecture

```
scripts/supply_backfill.py   → data/supply/room-dates.json   (یک‌بار + افزایشی)
scripts/supply_build.py      → data/supply-data.json + supply-dashboard.html
scripts/supply_snapshot.py   → data/snapshots/supply-YYYY-MM-DD.json (روزانه)
scripts/cron_supply_weekly.py→ اسنپ‌شات + بکفیل افزایشی + بازسازی (هفتگی)
```

کرون‌ها (در Hermes):
- **Jajiga Supply Daily Snapshot** — هر روز ۹:۰۰، `no_agent=True`، خاموش وقتی تغییری نباشد،
  در صورت تغییر «+N added / -M removed» با لینک اتاق‌ها تحویل می‌دهد.
- **Jajiga Supply Weekly Rebuild** — یکشنبه ۱۰:۰۰، اسنپ‌شات + بکفیل اتاق‌های جدید + بازسازی HTML.

لاuncherها در `~/AppData/Local/hermes/scripts/` (قانون مسیر اسکریپت کرون).

## Dashboard (supply-dashboard.html)

تک‌فایل، RTL، تیره، بدون وابستگی خارجی (SVG داخلی — Plotly لازم نیست). اجزا:

1. **KPI cards**: میزبان / اقامتگاه / این ماه (هر دو) / میانگین ماهانه / بدون تاریخ
2. **نمودار تجمعی** (area chart): منحنی اقامتگاه‌ها (آبی) + میزبان‌ها (نارنجی)
3. **نمودار ماهانه** (bar chart): ستون آبی = اقامتگاه جدید، نارنجی = میزبان جدید
4. **تایم‌لاین عمودی**: هر ماه = کارت با بج تعداد؛ کلیک → لیست نام میزبان‌ها و عنوان اقامتگاه‌ها
5. **کارت روستاها**: تعداد فعلی + بج «+N در ۲۰۲۶» (۱۲ روستای پرجمعیت)
6. **جدول جدیدترین میزبان‌ها** + **جدول جدیدترین اقامتگاه‌ها**

کانونشن‌های UI (همگی از تجربه‌های قبلی کاربر):
- ارقام انگلیسی monospace (`.en`)، سلول‌ها و سربرگ‌ها وسط‌چین، فقط نام میزبان راست‌چین
- مرتب‌سازی ۳ حالته (▼ → ▲ → ریست)، مدال طلا/نقره/برنز برای رتبه‌های ۱-۳
- تاریخ شمسی با نام ماه (`از تیر 1405`، `≈ خرداد 1398`) — تابع `g2j` تأییدشده
- بدون اسکرول داخلی جدول — کل صفحه اسکرول می‌شود، thead چسبان
- انیمیشن fade+slide (بدون blur)

## Caveats / محدودیت‌ها

- تاریخ اقامتگاه‌ها قبل از 2026-08-01 **تخمینی** است (عکس/نظر). آپلود مجدد عکس → تاریخ دیرتر از واقع.
- حذف اقامتگاه‌های تاریخی (قبل از شروع اسنپ‌شات) قابل بازیابی نیست — فقط از اسنپ‌شات به بعد
  حذف‌ها دقیق ثبت می‌شوند. نمودار تجمعی بر اساس مجموعه فعلی است.
- اتاق‌های بدون عکس/نظر (معمولاً غیرفعال) → «تاریخ نامشخص»، در سری ماهانه محاسبه نمی‌شوند.
- هشدار: هرگز دو استریم API موازی (WinError 10061) — بکفیل و اسنپ‌شات را هم‌زمان اجرا نکنید.
