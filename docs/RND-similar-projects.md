## 3. الگوهای قابل اقتباس (در ۳ لایه)

### لایه ۱ — الگوهای فوری (ساده، بدون تکنولوژی جدید)

1. **Telegram alerts از Letify** — قویترین الگو. اسکرپر + ربات تلگرام + اشتراک. ویژگیها:
   - ربات کامل: مشتری اقامتگاههای منتخب را دنبال کند
   - اعلان قیمتهای جدید، کلبههای جدید، تغییرات
   - `main_telegram.py` + `cli.py --interval` (اجرای مداوم)

2. **تاریخچه قیمت از IdeTracker** — «Save properties, record price history, and never miss a listing again». دقیقاً همان چیزی که در سند قبلی (ردیاب روزانه) پیشنهاد شد. تأیید جهانی بودن الگو.

3. **ایده «قیمت بهینه» از samuelklam** — مدل آماری که قیمت بهینه را پیشنهاد دهد. برای کاربر: «کلبه شما با این ویژگیها باید X تومان باشد».

### لایه ۲ — الگوهای میانمدت (نیازمند تکنولوژی متوسط)

4. **پیشبینی قیمت از End-to-End-Airbnb-Price-Prediction** — ML برای پیشبینی قیمت بر اساس ویژگیها (متراژ، امتیاز، نظرات، ظرفیت). با ۵۲ داده فعلی کم است ولی بعد از ۳۰ روز داده تاریخی شدنی است.

5. **پیشبینی درآمد میزبان از dmnguyen92** — «استراتژی قیمتگذاری برای میزبان جدید» — محاسبه درآمد تخمینی (قیمت × نرخ اشغال). خیلی مرتبط با کاربر که میزبان است.

6. **بخشبندی بازار از x-technology/airbnb-analytics** — تحلیل خوشهای بازار (اقتصادی/لوکس/ممتاز).

### لایه ۳ — الگوهای بلندمدت (جسورانه)

7. **داشبورد عمومی Inside Airbnb** — داخل Airbnb یک پروژه معروف است که داده Airbnb هر شهر را عمومی میکند. ایده: **نسخه جاجیگا** — داشبورد عمومی برای همه روستاهای مازندران. پروژه ما ۵۲ کلبه دارد ولی کل جاجیگا ۳۶۹ کلبه در بابلکنار است — اگر همه را پوشش دهیم یک **مرجع عمومی** میشویم.

8. **اتصال به API عمومی جاجیگا** — با الگوی `api.jajiga.com/api/room/{id}` میتوانیم کل ۳۶۹ کلبه را پوشش دهیم (فقط ۵۲ تا الان داریم). این بزرگترین فرصت است.
