## 1. 🎯 کشف: دو API جدید

### 1.1 نظرات: `GET /api/room/{id}/reviews?page=N&per_page=M`
```
https://api.jajiga.com/api/room/3297585/reviews?page=1&per_page=5
```
**بدون auth.** پاسخ:
```json
{
  "items": [
    {
      "id": 1209191,
      "content": "ممنون از میزبان عزیز...",
      "created_at": "2026-07-22T20:30:00.000000Z",
      "user": {"id": 3227391, "name": "الینا", "avatar": null, "gender": "female"},
      "host_reply": {"content": "مرسی از نظر ارزشمندتون🌱...", "created_at": "..."},
      "rating": 5
    }
  ],
  "pagination": {"total": 137, "count": 5, "page": 1, "per_page": 5}
}
```

**فیلدها:**
| فیلد | معنی |
|---|---|
| `id` | شناسه نظر |
| `content` | متن کامل نظر |
| `created_at` | تاریخ (ISO با Z) |
| `user` | کاربر: id, name, avatar, gender |
| `host_reply` | **پاسخ میزبان** (اگر داده باشد!) |
| `rating` | امتیاز همان نظر (4.7، 4.8، 5...) |

**Pagination:** `total` = کل نظرات، `per_page` تا ۱۰ کار میکند، صفحهبندی کامل

**فیلدهای کلیدی:**
| فیلد | معنی | نمونه |
|---|---|---|
| `active_rooms_count` | **تعداد اقامتگاههای فعال میزبان** | 5 |
| `rooms.items` | **لیست کامل اقامتگاهها** (قیمت، امتیاز، متراژ...) | — |
| `accept_rate` | درصد پذیرش درخواست رزرو | 54 |
| `response_time` | زمان پاسخ (دقیقه) | 401 |
| `host_communication_rate` | نرخ ارتباط از دید مهمانها | 4.4 |
| `user_verified` | تأیید شده | true |
| `created_at` | عضویت از چه تاریخی | 2023-05-20 |

### 3.2 محاسبات مشتق (Derived Metrics)
```python
# سطح میزبان (Host Level) — بر اساس مجموع رزروها
def host_level(total_books):
    if total_books >= 200: return "حرفهای"       # پرمیوم
    if total_books >= 50:  return "فعال"          # خوب
    if total_books >= 10:  return "تازهکار"       # در حال رشد
    return "مبتدی"                                 # کمفعالیت

# سطح کلاس اقامتگاه (Class) — ترکیب قیمت + امکانات
def room_class(price):
    if price >= 4000000:  return "لوکس"
    if price >= 2500000:  return "ممتاز"
    if price >= 1500000:  return "استاندارد"
    return "اقتصادی"
```

## 4. 🔗 جریان کامل داده (Data Pipeline)

```
برای هر room در all-cabins.json:
    │
    ├─ GET /api/room/{id}
    │    → قیمت، امتیاز، میزبان(id)، success_books، geo...
    │
    ├─ GET /api/room/{id}/reviews?page=1..N
    │    → همه نظرات + پاسخ میزبان
    │
    └─ GET /api/user/{host_id}          ← ⭐ جدید
         → پروفایل کامل + همه اقامتگاههای میزبان
         → برای هر اقامتگاه: قیمت، امتیاز، رزرو موفق، کلاس
```

**این یعنی:** از یک room میتوان به کل «امپراتوری» میزبان رسید!

## 5. 💡 ایدههای کاربردی

### 5.1 رتبهبندی میزبانها (Host Ranking)
- ستون «سطح میزبان» در داشبورد: مبتدی/تازهکار/فعال/حرفهای
- بر اساس `total_success_books` از همه اقامتگاهها
- **نمایش:** کدام میزبان بزرگترین «امپراتوری» بابلکنار را دارد

### 5.2 نقشه اقامتگاههای یک میزبان
- همه اتاقهای یک میزبان روی نقشه (با geo از room API)
- «محمدرضا ۵ کلبه در سیدکلا دارد» — نمای یکنفره

### 5.3 تحلیل کیفیت پاسخگویی
- `response_time` + `accept_rate` برای همه میزبانها
- مقایسه: میزبانهای پرسریع (لیلا: 30 دقیقه) vs کند (محمدرضا: 401 دقیقه)
- **نکته رقابتی برای کاربر:** پاسخ سریع = رزرو بیشتر

### 5.4 تحلیل نظرات (Review Analytics)
- برای هر کلبه: متن نظرات + پاسخ میزبان
- **کلمات کلیدی:** «تمیز»، «جکوزی»، «منظره»، «سوپرمارکت»...
- تشخیص نقاط قوت/ضعف هر کلبه از زبان مشتریها
- نرخ پاسخدهی میزبان به نظرات (host_reply وجود دارد یا نه)

### 5.5 هشدار میزبانهای در حال رشد
- میزبانی که `active_rooms_count` زیاد میشود = رقیب در حال توسعه
- میزبانی که رزروهایش صعودی است = باید مراقب بود

### 5.6 یافتن «میزبانهای غیرحرفهای»
- `accept_rate < 60` + `response_time > 300` = میزبان ضعیف
- کلبههای این میزبانها = فرصت جذب مشتری برای کاربر (مقایسه خدمات)

---

## 6. ⚠️ محدودیتها

1. **`active_rooms_count`** فقط اقامتگاههای **فعال** را میشمارد — اتاقهای حذفشده/غیرفعال دیده نمیشوند
2. **پروفایل API** ممکن است با دیتاست ما تفاوت داشته باشد (لیلا: ۴ در ما، ۲ در API) — **API منبع حقیقت است**
3. `per_page` برای نظرات تا ۱۰ تست شده (۵ هم کار میکند)
4. بدون auth — اما برای احترام، ۰.۵–۱ ثانیه بین درخواستها بگذار
5. `host_reply` همیشه وجود ندارد — فقط وقتی میزبان پاسخ داده

## 7. خلاصه

| قابلیت | API | فیلد کلیدی |
|---|---|---|
| نظرات کامل | `/api/room/{id}/reviews` | content, rating, host_reply |
| تعداد اقامتگاه میزبان | `/api/user/{id}` | `active_rooms_count` |
| همه اقامتگاههای میزبان | `/api/user/{id}` | `rooms.items[]` |
| قیمت/کلاس هر اقامتگاه | `/api/user/{id}` | `min_price` |
| رزرو موفق هر اقامتگاه | `/api/user/{id}` | `success_books` |
| کیفیت میزبان | `/api/user/{id}` | accept_rate, response_time |
| تأیید هویت | `/api/user/{id}` | user_verified |

**با این دو API میتوان یک «دیتابیس میزبان» کامل ساخت: پروفایل + همه اقامتگاهها + قیمت + کلاس + رزرو موفق — برای همه میزبانهای بابلکنار.**
