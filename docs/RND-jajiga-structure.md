## 1. معماری کلی

```
جاجیگا (Next.js SSR)
├── www.jajiga.com (وبسایت)
│   ├── /s/{city}/{type}     ← صفحات جستجو (فیلتر URL)
│   ├── /room/{id}           ← صفحات اقامتگاه
│   └── /public/sitemap/     ← sitemap عمومی (راز موفقیت!)
│
└── api.jajiga.com (Backend API)
    ├── /api/search          ← جستجو + آمار بازار
    ├── /api/room/{id}       ← جزئیات کامل اقامتگاه
    ├── /api/provinces       ← ۳۹ استان (شامل خارج از کشور!)
    └── /api/cities          ← شهرها (نیازمند province)
```

**نکته:** بدون Cloudflare، بدون نیاز به لاگین، از ایران قابل دسترسی. ✅

## 2. 🎯 کشف بزرگ: Sitemap عمومی (راهحل کامل ۳۶۹ کلبه)

### ساختار sitemap
```
https://www.jajiga.com/public/sitemap/sitemap.xml  ← ایندکس اصلی
├── sitemap_main.xml          ← صفحات اصلی
├── sitemap_search.xml        ← ۱۲,۳۹۹ URL جستجو (شهرها، روستاها، فیلترها!)
└── sitemap_rooms_chunk_0.xml ← ~۳,۰۰۰ اتاق
    ... (۲۴ chunk = ~۲۵,۰۰۰ اتاق)
```

### تأیید: room کاربر (3297585) در chunk 21 است ✅
**این یعنی sitemap_rooms شامل همه اتاقهای فعال جاجیگا است — از جمله همه کلبههای بابلکنار.**

### روش استخراج کامل (بهجای API خراب):
1. دانلود ۲۴ فایل `sitemap_rooms_chunk_{0..23}.xml`
2. استخراج همه `/room/{id}` — حدود ۲۵,۰۰۰ اتاق
3. فیلتر کردن با room API: هر ID → `api.jajiga.com/api/room/{id}` (۰.۴۵ ثانیه/اتاق)
4. برای بابلکنار: فقط اتاقهایی که `city.name == "بابلکنار"` هستند را نگه دار

> ⏱️ **زمان تقریبی:** ۲۵,۰۰۰ × ۰.۴۵s ≈ ۳ ساعت (یا ۳۶۹ × ۰.۴۵s ≈ ۳ دقیقه اگر فقط بابلکنار را بخواهیم — با فیلتر اولیه از sitemap_search)

## 7. 💡 فرصتهای جدید (بر اساس ساختار)

### 7.1 نقشه تعاملی (الان شدنی است!)
- `geo.lat/lng` در room API موجود است — میتوانیم همه کلبهها را روی نقشه Leaflet بگذاریم
- رنگ مارکر بر اساس قیمت، اندازه بر اساس رزرو موفق
- جاجیگا نقشه دارد ولی بدون جزئیات قیمت/رزرو

### 7.2 ردیاب میزبانها (جدید!)
- `host.accept_rate`، `host.response_time` در API است
- تحلیل: کدام میزبان بهترین پاسخگویی را دارد؟ کدام بیشترین رزرو موفق؟
- حتی میتوان رتبهبندی میزبانها ساخت

### 7.3 تحلیل تخفیفها (جدید!)
- `discounts` و `current_discount` در API است
- کدام کلبهها تخفیف مدتدار دارند؟ چه الگویی؟ (۱۰٪ از ۳ شب، ۲۰٪ از ۱۵ شب...)
- کدام کلبهها الان تخفیف لحظهای دارند؟

### 7.4 کیفیت رتبهبندی (جدید!)
- `ratings` شامل زیرشاخهها: accuracy, communication, cleanliness, location, checkin, value
- میتوان «بهترین از نظر تمیزی» یا «بهترین ارزش» را جدا کرد
- ⚠️ دقت: کاربر قبلاً «ارزش/متر» را رد کرده — این زیرشاخهها فقط بهعنوان اطلاعات تکمیلی

### 7.5 پایش کل بازار (جدید!)
- `api/search` بدون room: آمار کل کشور/استان/شهر را میدهد (rooms_count, min, max)
- Cron روزانه: ذخیره این آمار → نمودار رشد کل بازار جاجیگا
- «چند کلبه جدید این هفته در بابلکنار اضافه شده؟»

### 7.6 تشخیص کلبههای جدید
- مقایسه ID ها در دو زمان: ID جدید = کلبه جدید
- از sitemap: تاریخ `lastmod` = چه زمانی تغییر کرده

## 8. توصیههای فنی برای کار بهتر با سایت

1. **استفاده از sitemap بهجای search API** برای لیست کامل — همیشه بهروز و کامل
2. **استفاده از room API بهجای مرورگر** برای جزئیات — سریعتر (۰.۴۵s/room) و بدون محدودیت
3. **ذخیره `success_books`** — شاخص کلیدی تقاضا که در کارتها هم هست
4. **ذخیره `geo`** — برای نقشه و تحلیل موقعیت
5. **Cron روزانه برای meta آمار** — رشد بازار را بسنج
6. **Rate limit محترمانه:** ۲-۴ ثانیه بین درخواستها (نه بیشتر) — جاجیگا تحمل میکند
7. **آزمون دورهای** — sitemap ممکن است chunk جدید اضافه کند (الان ۲۴ تا)
