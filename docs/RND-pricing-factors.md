# RND-002 — معیارهای قیمتگذاری در جاجیگا (Pricing Factors Research)

تاریخ: 2026-08-01
وضعیت: فاز تحقیق — ورودی فاز ساخت الگوریتم قیمتگذاری

## 1. هدف

پیدا کردن **همه فاکتورهایی که روی قیمت شبانه (min_price) اقامتگاههای بابلکنار اثر میگذارند**،
با منبع داده دقیق برای هر فاکتور، تا بعداً الگوریتم قیمتگذاری روی آنها ساخته شود.

## 2. منابع داده (منبع = حقیقت)

| منبع | فیلدها | وضعیت |
|---|---|---|
| `data/hosts-babolkenar.json` (346 میزبان / 467 اتاق) | price, rating, reviews, success_books, bedrooms, floor_area, guests, is_plus/instant/clean, class | ✅ موجود |
| `data/all-cabins.json` (157 کلبه ۶ روستا) | price, occupancy_30, jacuzzi, pool | ✅ موجود |
| `GET api.jajiga.com/api/room/{id}` | **کاملترین منبع**: features[] (امکانات), properties[] (برچسبها), discounts[], ratings sub-scores, geo, land_area, cancellation, pictures, vr_photo, video_url, stays | ✅ نمونه ۱۰ اتاق گرفته شد |
| صفحه کارت جستجو `/s/babolkenar/cottage` | برچسبهای کارت: رزرو موفق، ممتاز، رزرو فوری، تخفیف مدت، خوشمنظره | ✅ مشاهده شد |
| صفحه اقامتگاه `/room/{id}` | بخش «امکانات» + بخش «ویژگیها» (برچسبها) + تقویم نرخ | ✅ مشاهده شد |
| `GET /api/nights` | تقاضا: occupancy_30، روزهای نیمهپر (turnover) | ✅ موجود در all-cabins |

## 3. نقشه کامل فاکتورها (6 گروه)

### A) فیزیکی و ساختاری (قویترین اثر)
- `floor_area` زیربنا — **corr +0.574** (قویترین همبستگی خطی)
- `land_area` زمین و محوطه (فقط در room API؛ در hosts DB نیست)
- `bedrooms` اتاق خواب — **corr +0.458**
- `guests`/`max_guest_number` ظرفیت — **corr +0.344**
- `floors_count`, `sleep_arrange` (چیدمان خواب)
- `types`/`regions` — نوع منطقه (جنگلی/روستایی/لبآب)
- `stays_min`/`stays_max` — حداقل/حداکثر اقامت

### B) امکانات — `features[]` (بخش «امکانات» صفحه)
کلیدها انگلیسی، شرح فارسی. از نمونه ۱۰ اتاق، **۲۸ کلید مجزا** دیده شد:

- **پایه (تقریباً همیشه موجود):** essentials, electricity, water, heating, cooler, stave, refrigerator, parking, islamictoilet, bathroom, tv, furniture
- **ارتقایی (افزایش قیمت):** jacuzzi (جکوزی)، pool/swimmingpool (استخر)، wifi، washer، hairdryer، janitor (نگهبان)، kitchen، table، barbecue، food (سرو غذای خانگی)، vacuumcleaner
- **ایمنی:** fireextingu، firstaidkit، firealarm، safetycard

> ⚠️ استخر در all-cabins: میانگین قیمت **5.88M با استخر vs 2.85M بدون** — بزرگترین تفکیککننده تکفاکتوره. جکوزی: 3.70M vs 3.14M.

### C) برچسبها — `properties[]` + بولیها (بخش «ویژگیها»)
**«خوشمنظره» برچسب واقعی و قابلگرفتن است** — از `properties[]` با name فارسی:
- خوش منظره (scenic) — در نمونه: قیمتها 1.2M تا 4M — **بهتنهایی تضمینکننده قیمت بالا نیست**
- مهمان نواز، جذاب، اقامتگاه خاص، خوش غذا، حیاط دار
- بولیهای API: `is_plus` (اقامتگاه ممتاز)، `is_instant` (رزرو فوری)، `is_clean`، `is_new`
- فیلترهای سایت (همان تاکسونومی): مـمـتــــاز، رزرو فوری، استخردار، خوش منظره، جکوزی، اقتصادی، لوکس، لبآب، بومگردی، حیاطدار، پتنواز، روستایی، مهماننواز، خوشغذا

### D) تخفیفها — `discounts[]` + `current_discount`
- `current_discount_percent` — تخفیف امروز/فردا (لحظه آخری) — نمونه: 10 تا 20٪
- `discounts[]` — تخفیف مدت اقامت: `{percent, type: period, min_nights}` — روی کارت: «10% تخفیف از 10 شب»
- ⚠️ قانون: قیمت پایه = `min_price` (باکس «نرخ هر شب از») — نه قیمت تخفیفی

### E) نظرات و اعتماد — `ratings` + reviews
- `ratings.total` (امتیاز کلی) — **corr +0.073 (ضعیف!)** و `ratings.count` (تعداد نظر)
- **زیرامتیازها (فقط در room API):** accuracy, communication, cleanliness, location, checkin, value
- `comments_grouped_by_rating`, `is_recently`, `is_bad_host`
- `success_books` (رزرو موفق) — **corr -0.074 (مثبت نیست!)**
- نرخ پاسخ میزبان (host_reply) از `/api/room/{id}/reviews`

### F) میزبان + مکان + سایر
- میزبان: `accept_rate` (+0.118)، `response_time`، `host_communication_rate`، `created_at` (سابقه)
- مکان: `geo {lat,lng}` → فاصله تا ساحل/جنگل، روستا (سیدکلا vs …)
- سایر: `cancellation_policy` (middle/hard/flexible)، تعداد عکس، `vr_photo`، `video_url`، `extra_price`

## 4. یافتههای کلیدی تحلیل اولیه (467 اتاق)

| فاکتور | همبستگی با قیمت | تفسیر |
|---|---|---|
| floor_area | **+0.574** | قویترین — متراژ اولویت اول |
| bedrooms | +0.458 | قوی |
| guests | +0.344 | متوسط |
| occupancy_30 | +0.321 | تقاضای فعلی با قیمت بالا همراهه |
| استخر | ~2x قیمت | بزرگترین تفاوت تکفاکتوره |
| rating | +0.073 | **تقریباً بیاثر** — امتیاز بالا قیمت نمیسازه |
| reviews / success_books | ~0 / منفی | **دادههای تقاضا علت نیستند، معلولاند** (ارزش خوب → رزرو زیاد، نه برعکس) |

**نتیجه مهم:** بازار بابلکنار روی **سایز فیزیکی + امکانات** قیمت میگذارد، نه روی امتیاز/نظر/رزرو.
رزرو بالا نتیجه قیمت منصفانه است، نه دلیلی برای گرانکردن. (نکته کلیدی برای الگوریتم خود کاربر)

## 5. شکاف داده (برای فاز جمعآوری)

برای ساخت الگوریتم این فیلدها باید برای نمونه بزرگتر (نه فقط ۱۰ اتاق) جمع شود:
1. `features[]` کامل هر اتاق → ماتریس امکانات (~30 ستون)
2. `properties[]` (برچسبها) — مخصوصاً خوشمنظره
3. زیرامتیازهای rating (مخصوصاً `location` و `cleanliness`)
4. `land_area`، `geo`، `types`/`regions`
5. `discounts[]` + `current_discount_percent`
6. `cancellation_policy`، `vr_photo`، `video_url`، تعداد عکس
7. (اختیاری) متن نظرات برای ماین کلمات کلیدی (جکوزی/استخر/چشمانداز)

## 6. گام بعدی پیشنهادی (نیاز به تأیید)

**فاز ۱ — جمعآوری نمونه:** ~۴۰–۵۰ اتاق طبقهبندیشده از ۴ کلاس قیمتی (اقتصادی/استاندارد/ممتاز/لوکس)
→ ذخیره در `data/pricing/sample_full/` + ساخت `data/pricing/pricing-dataset.csv` (هر ردیف = ۱ اتاق، هر ستون = ۱ فاکتور)
→ زمان تقریبی: ~۴ دقیقه (با delay 2-4s، یک استریم)

**فاز ۲ — تحلیل:** ماتریس همبستگی کامل، تحلیل چندمتغیره، وزن هر فاکتور

**فاز ۳ — الگوریتم:** مدل قیمت پیشنهادی (مثلاً: قیمت پایه = f(متراژ، اتاق، ظرفیت، امکانات، برچسب، روستا) + پریمیوم استخر/جکوزی/خوشمنظره)
