# پلن: تمیزسازی عنوان کلبه‌ها + ستون مستقل میزبان + ویرایش با ذخیره‌سازی

> **Goal:** (۱) عنوان هر کلبه از نام روستا پاک شود چون ستون جداگانه روستا وجود دارد، (۲) ستون «روستا» باقی بماند، (۳) ستون جدید «میزبان» به‌عنوان ستون مستقل **بعد از ستون عنوان** اضافه شود (فعلاً مقدار «نام میزبان»)، (۴) اطلاعات کلبه‌ها قابل ویرایش باشد و بعد از رفرش حفظ شود.

**Architecture:** تک‌فایل `dashboard.html` + `data/all-cabins.json`. تمیزسازی عنوان با اسکریپت Python روی JSON، افزودن فیلد `host` به هر رکورد، و سیستم ویرایش با مودال + `localStorage` (کلید نسخه‌دار `jajiga_tracker_v1`).

**Tech Stack:** HTML/CSS/JS خالص + Python برای پاکسازی عنوان‌ها.

## تغییرات

### Task 1: تمیزسازی عنوان کلبه‌ها (Python)
- **Modify:** `data/all-cabins.json`
- حذف از انتهای عنوان:
  - `- سیدکلا` / `- سید کلا` / `- قران تالار` / `- قرآن تالار` / `- قرآن تلار` / `- گونه کلا` / `- شیردارکلا`
  - `در بابلکنار` (وسط/انتهای عنوان وقتی بعدش روستا باشد یا تنها باشد)
  - `در سیدکلا` / `در گونه کلا` / `در شیردارکلا` / `در سوادکوه` / `در شیرگاه` (به‌عنوان پسوند مکان)
- **حفظ** پسوندهای مشخصه: `- ۲`, `- ط بالا`, `- ۳ خوابه`
- مثال: `کلبه سوئیسی با جکوزی در بابلکنار - گونه کلا` → `کلبه سوئیسی با جکوزی`
- **Verification:** خروجی هر ۵۲ عنوان چاپ و بررسی شود — هیچ عنوانی نباید نام روستا داشته باشد

### Task 2: افزودن فیلد `host`
- هر رکورد JSON: `"host": "نام میزبان"` (مقدار موقت)
- بلوک `ALL_CABINS` در `dashboard.html` هم‌زمان با JSON بازسازی شود

### Task 3: ستون «میزبان» در جدول (بعد از «عنوان»)
- ترتیب ستون‌ها: `# | عنوان | میزبان | روستا | قیمت/شب | ...`
- سلول میزبان: `c.host` (فعلاً «نام میزبان»)
- `SORT_COLS`: اضافه کردن `host` بین `title` و `village`
- ستون روستا دست‌نخورده باقی می‌ماند (فیلتر/رنگ/مرتب‌سازی حفظ)

### Task 4: دکمه ویرایش ✏️ در هر ردیف
- کنار دکمه expand در ستون آخر

### Task 5: مودال ویرایش + ذخیره localStorage
- فیلدها: عنوان، میزبان، روستا، قیمت، خواب، متراژ، ظرفیت، امتیاز، نظرات، وضعیت، جکوزی، استخر
- ذخیره → `localStorage.setItem('jajiga_tracker_v1', ...)`
- validation عددی سبک

### Task 6: لود با اولویت localStorage + بازنشانی
- `init()`: localStorage > دیتای داخلی
- دکمه «بازنشانی» → پاک کردن localStorage + رفرش

### Task 7: تست
- ویرایش → رفرش → باقی می‌ماند
- بازنشانی → دیتای اصلی
- فیلتر/مرتب‌سازی/صفحه‌بندی سالم
