# تبدیل خروجی اکسل از CSV خشک به XLSX حرفه‌ای (رنگی + فرمت‌دار)

> **Goal:** دکمه‌های «اکسل تقویم» و «اکسل دیتابیس» فایل XLSX واقعی با رنگ‌، فرمت عدد، و هدر حرفه‌ای تولینند (نه CSV خالی).

**وضعیت فعلی (مشکل):**
- خروجی فعلی = `text/csv` با BOM + پسوند `.csv`
- بدون رنگ، بدون فرمت عدد، بدون استایل → «خشک و خالی»
- کتابخانه‌های قابل استفاده: `openpyxl 3.1.5` و `xlsxwriter 3.2.9` (نصب‌شده)

**معماری پیشنهادی:** تولید XLSX در مرورگر با SheetJS (xlsx.js) از CDN — بدون سرور، بدون تغییر ساختار داشبورد. فایل نهایی `.xlsx` با فرمت‌دهی کامل.

---

## گام‌ها

### Task 1: بارگذاری SheetJS در HTML
- Modify: `competitor-radar.html` → اضافه کردن `<script src="https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js"></script>` قبل از اسکریپت‌های خروجی
- Fallback: اگر CDN در دسترس نبود، پیام «لطفاً اتصال اینترنت را بررسی کنید» نشان بده
- Verify: در کنسول مرورگر `XLSX` تعریف شده باشد

### Task 2: جایگزینی خروجی تقویم (future) با XLSX فرمت‌دار
- Modify: `scripts/build_radar_dashboard.py` → اسکریپت `export_js` (خطوط ~549-574)
- ساخت شیت با این ستون‌ها:
  - `اتاق` (نام اقامتگاه، عرض ۳۰)
  - `روستا` (عرض ۱۲)
  - `میزبان` (عرض ۱۸)
  - ستون‌های تاریخ: `WD DD MMM` (مثال: `چها 21 مرداد`) — عرض ۱۰
  - `۳۰ روز`، `۶۰ روز`، `۹۰ روز` (درصد، عرض ۸)
  - `میانگین شب` (تومان، عرض ۱۲)
  - `تخفیف`، `پیک` (عرض ۸)
- فرمت‌دهی:
  - هدر: پس‌زمینه `#1e3a5f`، متن سفید، bold، وسط‌چین
  - سلول‌های تاریخ:
    - پر (booked): پس‌زمینه `#dc2626` (قرمز)، متن سفید
    - خالی (free): پس‌زمینه `#16a34a` (سبز)، متن سفید
    - نیمه‌پر (half): پس‌زمینه `#ea580c` (نارنجی)، متن سفید
    - پیک (peak): پس‌زمینه `#7c3aed` (بنفش)، متن سفید
    - گذشته (past): پس‌زمینه `#475569` (خاکستری)، متن سفید
    - بدون داده: پس‌زمینه `#1e293b` (تیره)، متن `#64748b`
  - متن سلول: وضعیت + قیمت (مثلاً: `پر · 2.4M · -10%`)
  - ستون قیمت: عدد انگلیسی با جداکننده هزار + پسوند `M`
  - ستاق اشغال: عدد انگلیسی + `%`
  - ردیف خودی (own): bold + حاشیه سبز روشن
  - Freeze: سطر ۱ + ستون اول (A)
  - Auto-filter: روی هدر
  - عرض ستون‌ها خودکار
- Verify: کلیک روی «اکسل تقویم» → دانلود `radar-YYYY-MM-DD.xlsx` با رنگ‌ها

### Task 3: جایگزینی خروجی دیتابیس (past) با XLSX فرمت‌دار
- Modify: `scripts/build_radar_dashboard.py` → اسکریپت `past_export_js` (خطوط ~577-600)
- ساخت شیت با ستون‌ها: `اتاق` + تاریخ‌های گذشته + متریک‌ها
- فرمت‌دهی مشابه Task 2 (رنگ‌ها + هدر + freeze)
- Verify: کلیک روی «اکسل دیتابیس» → دانلود `radar-db-YYYY-MM-DD.xlsx`

### Task 4: بازسازی داشبورد + تست
- Run: `python scripts/build_radar_dashboard.py`
- Verify: `competitor-radar.html` شامل `<script src="...xlsx...">` است
- تست در مرورگر: باز کردن `competitor-radar.html` → کلیک هر دکمه → فایل XLSX با رنگ دانلود می‌شود

## ریسک‌ها / نکات
1. **CDN در دسترس نباشد** → Fallback به CSV قدیمی + پیام هشدار
2. **حجم فایل** با ۳۵ اتاق × ۴۴ ستون ≈ ۱۵۰۰ سلول رنگی → ~۵۰KB (قابل قبول)
3. **اعداد فارسی vs انگلیسی** → قیمت‌ها و درصدها انگلیسی (مثل داشبورد)، متن وضعیت فارسی
4. **SheetJS حجم ~۹۵۰KB** → فقط یک بار لود می‌شود (کش مرورگر)
